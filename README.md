# Конструктор КП — робот-мойка DKR 360

Веб-инструмент для отдела продаж DKR GROUP: пошаговый визард для сборки коммерческого предложения на робот-мойку **DKR 360** (комплектации Business / Premium / Cosmo), с живым расчётом стоимости и готовым печатным документом (PDF / Word / Excel).

Полный аналог конструктора для линейки МСО (моек самообслуживания), адаптированный под робот 360.

## Быстрый старт

Файл `robot_kp_constructor.html` — самодостаточная веб-страница (HTML + CSS + JS в одном файле, все изображения встроены как base64). Достаточно открыть его в браузере:

```bash
open robot_kp_constructor.html   # macOS
# или просто перетащить файл в браузер
```

Единственная зависимость из интернета — библиотека SheetJS (`xlsx`) для экспорта в Excel, подключается с cdnjs.cloudflare.com; для полноценной работы нужен доступ в интернет (сама страница работает и офлайн, кроме кнопки «Excel»).

**Пароль входа:** `dkr2026`

## Что внутри

- **Шаг 1 — Проект и клиент**: название проекта, клиент, контактное лицо, адрес объекта, количество роботов.
- **Шаг 2 — Комплектация**: Business / Premium / Cosmo, с ценой и списком того, что включено / доступно за доплату / отсутствует.
- **Шаг 3 — Доп. опции**: платные опции, доступные для выбранной комплектации (пена-лава, мойка днища, боковая мойка, доп. сушка и т.д.), плюс опции с ценой «по запросу».
- **Шаг 4 — Итог**: скидка (0–15%), условия поставки, постраничный предпросмотр готового КП.

Итоговый документ КП всегда включает, помимо спецификации и цены: сравнение с китайскими аналогами, требования к помещению (с чертежом) и фотографии/чертежи готовой мойки.

## Обновление данных

Все данные (комплектации, опции, цены, тексты) заданы прямо в JS-коде `robot_kp_constructor.html`, в начале скрипта: `robotPackages`, `BASE_EQUIP`, `addons`, `noPriceAddons`, `COMPANY`, `TERMS`, `CHINA_DIFF`, `ROOM_REQ`. Изменил цену/опцию — поправь соответствующий блок и файл снова готов к использованию, пересборка не нужна.

Если меняются исходные чертежи/фото — обнови файлы в `assets/`, перекодируй в base64 (`base64 -i assets/имя.jpg`) и подставь в соответствующую константу (`LOGO`, `IMG_FRONT`, `IMG_ISO`, `IMG_LABELED`, `IMG_ROOM`) в начале скрипта.

Подробности по принятым решениям (что сознательно не попало в клиентский КП, какие цифры уточнить) — в `docs/Решения-конструктора.md`.
